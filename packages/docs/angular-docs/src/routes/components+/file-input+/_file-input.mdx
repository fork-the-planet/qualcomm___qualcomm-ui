## Overview

Use File Input when a form needs one input-style field for selecting a single file. It uses File Upload selection state for validation and file picker behavior, and QDS input styling for labels, focus state, error text, sizes, and inline clearing.

Use [File Upload](/components/file-upload) for multi-file lists, previews, drag-and-drop upload areas, and rejected-file workflows.
