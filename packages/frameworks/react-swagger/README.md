# @qualcomm-ui/react-swagger

Swagger Plugin Disclaimer

The majority of the code in this package was taken as-is from the Swagger UI repository, which is a legacy codebase. As a result, you'll find many anti-patterns in this folder, particularly concerning loose type safety.

We've overridden many components for a better look and feel, but the functionality largely remains the same. We're working a replacement for Swagger UI, so this package will eventually be deprecated.
